# Alert Component Usage

## Описание

Универсальный компонент Alert для отображения уведомлений об успехе, ошибках, предупреждениях и информации.

## Использование

### 1. Импорт хука

```javascript
import { useAlert } from '../hooks/useAlert';
```

### 2. Получение функций

```javascript
const { success, error, warning, info } = useAlert();
```

### 3. Вызов уведомлений

```javascript
// Успех
success('Операция выполнена успешно!', 'Успех');

// Ошибка
error('Произошла ошибка', 'Ошибка');

// Предупреждение
warning('Внимание! Проверьте данные', 'Предупреждение');

// Информация
info('Полезная информация', 'Информация');
```

## Параметры

- `message` (string) - текст сообщения
- `title` (string, optional) - заголовок уведомления
- `duration` (number, optional) - длительность показа в миллисекундах (по умолчанию 5000ms)

## Типы уведомлений

- `success` - зеленый цвет, иконка галочки
- `error` - красный цвет, иконка крестика
- `warning` - желтый цвет, иконка восклицательного знака
- `info` - синий цвет, иконка информации

## Особенности

- Автоматическое исчезновение через указанное время
- Возможность закрыть вручную
- Плавные анимации появления/исчезновения
- Отображение в правом верхнем углу
- Поддержка множественных уведомлений
- Адаптивный дизайн
