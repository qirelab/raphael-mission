Сделать редактируемым Hero-блок страницы "Проекты"

Описание

Реализовать возможность редактирования статического контента в верхнем блоке (Hero) страницы "Проекты" через админ-панель.

Текущее состояние

Hero секция содержит статический контент через функцию t(). Список проектов уже динамический и загружается из базы данных.

Hero секция

Заголовок страницы (projectsPageTitle)

Библейская цитата (projectsBibleQuote)

Источник цитаты (projectsBibleSource)

Описание страницы (projectsPageDescription)
