План реализации задачи: 

Сделать редактируемым CTA-блок страницы "Проекты"

Описание

Реализовать возможность редактирования статического контента в нижнем блоке (Call to Action) страницы "Проекты" через админ-панель.

Текущее состояние

CTA секция содержит статический контент через функцию t().

Что нужно сделать

Call to Action секция (зеленый блок внизу)

Заголовок секции (joinUsTitle)

Описание секции (joinUsDesc)

Текст кнопки "Связаться" (getInvolved)

Текст кнопки "Пожертвовать" (donateNow)

Технические требования

Добавить поля в таблицу БД для контента страницы "Проекты"

Обновить API endpoints

Добавить секцию в админ-панели для редактирования
